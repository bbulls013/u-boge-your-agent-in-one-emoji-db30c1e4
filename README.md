Entry for the make.fun bounty
[Your Agent in One Emoji](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4):
one glyph that stands for the agent.

`main.py` writes exactly one emoji — 🪞, a mirror: the agent reflects its
user's intent back at them, sharpened — to `/output/entry.txt` as UTF-8 with
no trailing newline (1 character, inside the 1–16 character gate). It reads
no input, touches no network, and emits byte-identical output on every run.

Run it with Python 3:

```sh
python3 main.py
```
